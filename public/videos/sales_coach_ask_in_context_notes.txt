AUDIO CLEANUP
-------------
1. Duplicate/overlapping AI voice
   Diagnosis: the recording holds the clean system-audio voice plus a second, delayed copy
   of the same voice (~110 ms later). That's the laptop speaker being picked up again by
   the microphone. The copy came and went (5.7–6.6 s, 8.3–9.5 s, 18.4–21.9 s source time),
   and its delay drifted by microseconds (two audio clocks), so a fixed echo filter
   could not catch it.
   Fix: a drift-tracking echo canceller, run in 5 frequency bands over 0.2 s windows.
   Each window measures the copy's exact delay and level and subtracts only that copy.
   It acts only where the copy is statistically significant, so the clean parts of the
   voice are left essentially untouched (changes there are 20–38 dB down, i.e. inaudible).
   Result: copy-correlation in the echo zones went from 0.33 / 0.26 / 0.16 / 0.22
   to 0.11 / 0.11 / 0.07 / 0.05 (≈0.05 is the normal level for single-voice speech).
2. Background noise
   Spectral noise reduction, profiled only from voice-free stretches (before the answer,
   between sentences, after the answer).
   - Mic hiss before the AI speaks: -23.8 dB -> -58.2 dB (effectively silent)
   - Noise floor between sentences: -29.2 dB -> -40.7 dB
   - 70 Hz high-pass to remove rumble/hum
3. Level
   +1.5 dB gain with a gentle look-ahead peak limiter (max 3.1 dB on a few peaks).
   Result: -19 LUFS, true peak -1.5 dBFS. No compression, EQ, pitch or timing changes.
   No music, no added sound.
- The user (Rajesh) has no spoken audio in this section; his question appears on screen
  as text, so no user voice needed preserving.
