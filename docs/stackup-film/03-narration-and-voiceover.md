## 6. AI voiceover: what I need from you

**I could not generate the voice in this session.** The cloud environment's network policy blocks `api.elevenlabs.io` (and every other text-to-speech host). I haven't substituted a robotic or fake voice. The pipeline is built and runs the moment access exists.

### What you need to provide

1. **An ElevenLabs account and plan.** I couldn't open their site from here to confirm current terms. Before choosing a plan, check on <https://elevenlabs.io/pricing> that it **includes a commercial-use licence** (a portfolio film shown to recruiters is professional use) and has enough characters. The full script is about 1,400 characters, so a few regenerations are well within small plans. Don't assume your Claude subscription includes this; it doesn't.
2. **An API key** with Text to Speech access (ElevenLabs → Developers / API keys).
3. **A voice ID.** In ElevenLabs' Voice Library, filter for *Female · Young · English · Indian accent*, choose a conversational (not "advertisement") voice, add it to *My Voices*, and copy its **Voice ID**. Say which one you picked and I'll tune stability and style for it.

### How to give them to me (never paste a key into the chat)

In this cloud environment's settings (the environment menu in the session title bar → **Edit**):
- **Network access:** add `api.elevenlabs.io` under Allowed domains (keep "Allow package managers" ticked).
- **Environment variables** (or Network secrets, where offered): `ELEVENLABS_API_KEY` and `ELEVENLABS_VOICE_ID`.

A new session picks these up. Then:

```bash
cd film
npm run voiceover        # generates public/voiceover/S01.mp3 … S17.mp3 and measures each clip
npm run voiceover:check  # re-checks the fit using the real clip lengths
npm run render           # final MP4 with voice + music
```

Alternatively, run `npm run voiceover` on your own machine with the two variables set, and commit the generated `public/voiceover/*.mp3` and `src/voiceover-manifest.json`.

### How it's integrated
- One clip per scene, placed at that line's start frame, so each sentence stays locked to its scene even if another scene is retimed.
- Request stitching (`previous_text` / `next_text`) keeps intonation continuous across clips.
- Captions are timed inside each measured clip.
- The voice starts at 0:00.2 and the last line ends ~0.7 s before the final frame.
